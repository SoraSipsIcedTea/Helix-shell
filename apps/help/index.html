So funktioniert Helix

Helix ist ein kleiner Server auf deinem Handy mit einem Desktop obendrauf. Jede App läuft in ihrem eigenen Fenster und hat ihre eigene Adresse.

Desktop und Handy-Ansicht

Auf breiten Bildschirmen siehst du Fenster, die du ziehen, vergrößern und an den Rand schieben kannst. Auf dem Handy füllt jedes Fenster den Bildschirm. Unten wechselst du zwischen Start, Fenster und Apps. Die Ansicht stellst du in Einstellungen, Desktop um.

  • Das Helix-Zeichen oben links öffnet die Übersicht mit allen Fenstern.
  • Uhr antippen: Kalender und Benachrichtigungen.
  • Symbole oben rechts: Schnelleinstellungen wie Hell/Dunkel und Wach halten.
  • Lange drücken (oder Rechtsklick) auf ein App-Symbol: Menü mit Direktlinks, Dock und App-Infos.
  • Die Zurück-Taste von Android geht zuerst in der App zurück, dann zum Start.

Apps installieren und aktualisieren

Im App-Center installierst du Pakete: ein ZIP, ein Applanner-Projekt (.json) oder eine einzelne HTML-Datei. Helix schlägt vor, welche App das Paket aktualisiert, und zeigt dir vor dem Installieren, welche Dateien sich ändern. Vor jedem Update legt Helix eine Sicherung an.

Teilst du ein Paket aus einer anderen Android-App mit Helix, öffnet sich das App-Center von selbst. Hat eine App eine Update-Adresse, prüft „Nach Update suchen“ sie direkt.

Alternativ verbindest du einen Ordner: Helix startet die App dann direkt von dort. Praktisch, wenn du sie selbst entwickelst.

Dateien

Dateien zeigt deinen persönlichen Ordner, verbundene Ordner und, wenn du es erlaubst, den ganzen Gerätespeicher. Apps fragen beim ersten Zugriff, ob sie deine Dateien sehen dürfen.

Für App-Entwickler

Jede App bekommt window.Helix. Ein paar Beispiele:

Helix.fs.request()                   // Dateizugriff erbitten
Helix.fs.list('home', 'Dokumente')
Helix.shared.open('helix')           // gemeinsame Ablage der Suiten
Helix.shell.notify('Fertig', 'Export gespeichert')
Helix.shell.open('aura', 'index.html#heute')
Helix.shell.update()                 // im App-Center nach Updates suchen

Mit einer helix-app.json im Paket legst du Name, Version, Symbol, Direktlinks und eine Update-Adresse fest:

{
  "id": "meine-app",
  "name": "Meine App",
  "version": "1.2.0",
  "icon": "icon.png",
  "update": "https://example.org/meine-app.zip",
  "shortcuts": [{ "name": "Neu", "path": "index.html#neu" }]
}

Die DevTools (eruda) öffnest du über das Fenstermenü. Im Terminal zeigt logs alle Konsolen-Ausgaben live.

Tastatur

  • Strg + Leertaste oder Meta: Übersicht
  • Alt + F4: Fenster schließen
  • Esc: Menü, Dialog oder Übersicht schließen

Der Desktop ist austauschbar

Auch der Desktop selbst ist eine Web-App. Im App-Center unter Helix-Desktop aktualisierst du ihn, spielst einen anderen ein oder gehst zum eingebauten zurück. Deine Einstellungen bleiben dabei erhalten.
